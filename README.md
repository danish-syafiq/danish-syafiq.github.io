# Danish Syafiq — Portfolio

A minimal, dark portfolio site built with plain HTML, CSS and JavaScript. No frameworks and no build step.

## Files

- `index.html`: the content (edit text here)
- `style.css`: the design
- `script.js`: the animations (scroll reveal, decrypt text, word fade, counters, cert filter, photo lightbox)
- `images/`: event photos

## Before you publish

Open `index.html` and search for `TODO`:

1. Change `your.email@example.com` to your email.
2. Change `YOUR-USERNAME` to your GitHub username.

## Deploy to GitHub Pages

1. Create a new public repo named **`<your-username>.github.io`**.
2. Upload `index.html`, `style.css`, `script.js`, the `images` folder and this README (Add file → Upload files → Commit).
3. Go to **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, then pick `main` and `/ (root)` and save.
4. Wait 1–2 minutes. Your site will be live at `https://<your-username>.github.io`.

## Adding a certification

Copy one `<article class="cert ...">` block in `index.html` and change the text.
`data-c` sets the filter tab: `comptia`, `google`, `fortinet`, `cisco` or `other`.
